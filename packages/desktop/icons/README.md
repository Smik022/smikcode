# App icons

SmikCode's icons are a pixel "S" in three channel colours: prod is green phosphor, beta amber and dev cyan. They are
generated by `scripts/generate-icons.cjs`, which draws the artwork from an SVG and needs no image library, only the
Electron binary that is already installed. From `packages/desktop`:

```bash
node_modules/.bin/electron scripts/generate-icons.cjs
```

(If that shim is not there, run the `electron.exe` under `node_modules/.bun/electron@*/node_modules/electron/dist/`.)

For every channel folder it rewrites each PNG at its existing size and in the right shape (rounded square, iOS
full-bleed square, Android round and adaptive foreground), builds `icon.ico` and `icon.icns`, writes `dock.png` with
macOS's Big Sur inset, sets the Android adaptive background colour, and refreshes `packages/app/public/favicon-smik.svg`.
The web app's favicon, touch icon and PWA icons are read from these folders by `packages/app/vite.icons.ts`.

To change the design, edit `GLYPH`, `CHANNELS` or `source()` in the script and run it again.

# Tauri icons (upstream process, no longer used)

The folders keep the layout upstream's Tauri tooling produced. This was the process they used before SmikCode:

- Save source image as `app-icon.png` in `packages/desktop`
- `cd` to `packages/desktop`
- Run `bun tauri icon -o src-tauri/icons/{environment}`
- Use [Image2Icon](https://img2icnsapp.com/)'s 'Big Sur Icon' preset to generate an `icon.icns` file and place it in the appropriate icons folder

For unpackaged Electron on macOS, `app.dock.setIcon()` should use a PNG, so `dock.png` in each channel folder carries the
same inset as that channel's `icon.icns`.
